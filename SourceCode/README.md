# SourceCode - Bài Tập Tuần 2 (Kotlin / Jetpack Compose)

Thư mục lưu trữ toàn bộ mã nguồn Kotlin của dự án Android **Bài Tập Tuần 2**.

## Danh sách các file trong thư mục:
- **`SourceCode.txt`**: File tổng hợp toàn bộ code Kotlin của dự án (bao gồm `MainActivity.kt`, giao diện Theme và các file Gradle Kotlin Script `.kts`).
- **`SourceCode.kt`**: File Kotlin tổng hợp toàn bộ mã nguồn ứng dụng (`MainActivity.kt` và theme).
- **`MainActivity.kt`**: File mã nguồn chính chứa toàn bộ giao diện và logic của 4 bài tập:
  - **Bài 1 - Máy tính đơn giản (`CalculatorScreen`)**: Thực hiện các phép tính cơ bản (+, -, *, /) với Compose UI.
  - **Bài 2 - Danh sách sinh viên & Nullable (`StudentListScreen`)**: Quản lý thông tin sinh viên, kiểm tra và xử lý dữ liệu `null` (email, SĐT).
  - **Bài 3 - Xếp loại học lực (`ClassificationScreen`)**: Phân loại học lực theo điểm số sử dụng cấu trúc rẽ nhánh `if / else`.
  - **Bài 4 - Bảng điểm lớp & Thống kê (`ScoreboardScreen`)**: Tính điểm trung bình, tìm điểm cao nhất, thống kê số sinh viên giỏi và sinh viên chưa có điểm.
- **`ui/theme/`**: Các file định nghĩa Theme, Màu sắc (`Color.kt`) và Typography (`Type.kt`, `Theme.kt`).
