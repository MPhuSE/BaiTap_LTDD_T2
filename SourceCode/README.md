# SourceCode - Bài Tập Tuần 2 (Android Jetpack Compose)

Thư mục chứa toàn bộ dự án Android Studio và mã nguồn các bài tập tuần 2.

## Cấu trúc:
- **`MainActivity.kt`**: File Kotlin chính chứa mã nguồn toàn bộ 4 bài tập:
  - **Bài 1**: Máy tính đơn giản (`CalculatorScreen`)
  - **Bài 2**: Danh sách sinh viên & Nullable (`StudentListScreen`)
  - **Bài 3**: Xếp loại học lực (`ClassificationScreen`)
  - **Bài 4**: Bảng điểm lớp & Thống kê (`ScoreboardScreen`)
- **`app/`**: Thư mục module Android chứa mã nguồn (`src/main/java/...`), tài nguyên (`res/`), và manifest.
- **`gradle/`**, **`build.gradle.kts`**, **`settings.gradle.kts`**: Cấu hình build Gradle cho dự án.
